### Cómo trabajo

- El contrato de la API y los tests van en el mismo corte que la funcionalidad.
- Primero corre en local. La nube entra cuando el servicio ya se puede apagar y el coste está escrito.
- Prefiero un monolito modular claro antes que partir el sistema en servicios que todavía no lo necesitan.
